# LLM Security Prototype v1

Prototype of a multi-layer security system for Large Language Models (LLM).

## Features

- Input prompt filtering
- Prompt injection detection
- Jailbreak detection
- Sensitive data anonymization
- Output filtering
- Logging system
- Modular pipeline architecture
